# Modelo Conceitual

## Entidades
- Usuario
- Categoria
- Fornecedor
- Produto
- Movimentacao

## Relacionamentos
- Categoria 1:N Produto
- Fornecedor 1:N Produto
- Produto 1:N Movimentacao
- Usuario 1:N Movimentacao

## Descrição
O modelo representa o controle de estoque da confeitaria. Produtos pertencem a categorias, são associados a fornecedores e possuem movimentações de entrada e saída registradas por usuários.
