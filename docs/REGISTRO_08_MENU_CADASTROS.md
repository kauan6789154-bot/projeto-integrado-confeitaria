# Registro 08 - Menu Principal e Cadastros

## Objetivo
Transformar o menu de validação em um menu funcional conectado ao MySQL.

## Funcionalidades implementadas
- listagem de produtos;
- listagem de categorias;
- listagem de fornecedores;
- cadastro de categoria;
- cadastro de fornecedor;
- cadastro de produto;
- validação de campos obrigatórios;
- validação de valores numéricos;
- validação das chaves estrangeiras;
- controle de permissão por perfil.

## Controle de acesso
O Administrador pode realizar os cadastros.

O Operador pode consultar os dados, mas não possui as permissões administrativas de cadastro.

## Persistência
Todos os cadastros desta etapa são gravados diretamente no MySQL.
